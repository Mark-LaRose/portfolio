## Local Development

Clone the repository:

```bash
git clone https://github.com/Mark-LaRose/Portfolio.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```

---

## Production Build

Build the project:

```bash
npm run build
```

Run the production server:

```bash
npm run start
```
